= Portfolio

I've worked mostly as a solo technical writer to create technical documentation. I've a diverse range of writing samples in my portfolio, including online help systems, user guides, and troubleshooting material I can show interested parties in person. This page provides an overview of documentation from several recent technical writing projects, and samples I've developed specifically for my online portfolio. Click the links to view the samples.
